# flood_events vs floodWarn 비교 분석

---

## 1. 기록 기준

### flood_events_han_2024_2025.csv

| 항목 | 내용 |
|------|------|
| 데이터 소스 | HRFCO 수문자료 OpenAPI (`waterlevel/list/1H`) |
| 기록 단위 | 관측소 × 날짜 (일별) |
| 이벤트 판단 기준 | 해당 날짜의 **시간별 수위 중 일별 최대값**이 obsFinal의 `aFLAdvisory(m)` 또는 `aFLAlert(m)` 기준수위를 초과할 때 |
| 레벨 구분 | ADVISORY (주의보 기준 초과), ALERT (경보 기준 초과) |
| 대상 지점 | obsFinal에서 한강·안성천 권역이고 `designFlood` 컬럼 유효값이 있는 관측소 (스크립트 실행 시 선택된 13개 지점만 결과 존재) |
| 특보 발령 여부 무관 | 수위가 기준을 넘으면 무조건 기록 — **공식 특보 발령 없이도 기록 가능** |
| 기록 범위 | 2024-01-01 ~ 2025-12-31 |

### floodWarn_2024_2025_parsed.csv

| 항목 | 내용 |
|------|------|
| 데이터 소스 | n.flood.go.kr 홍수정보시스템 발령서 (한강홍수통제소 공식 발령 이력) |
| 기록 단위 | 관측소 × 특보 이벤트 (발령·변경·해제 각각 한 행) |
| 이벤트 판단 기준 | **담당 기관(한강홍수통제소 등)이 공식 홍수예보를 발령한 시점** — 관측 수위 + **예측 수위** 기반으로 결정 |
| 레벨 구분 | 주의보, 경보 (변경으로 격상 포함) |
| 대상 지점 | 홍수특보가 실제 발령된 모든 지점 (designFlood 미지정 지점 포함 가능) |
| 수위 임계값과의 괴리 가능 | 예보 기반이므로 관측 수위가 기준에 미달해도 발령 가능 |
| 기록 범위 | 2024-07-17 ~ 2025-09-20 (실제 발령 이력 범위) |

**핵심 차이**: flood_events는 "실측 수위 ≥ 기준수위"인 날을 사후 산출한 것이고, floodWarn은 실시간 예보 판단에 기반한 공식 발령 이력이다.

## 2. flood_events에만 있고 floodWarn에 없는 홍수특보

**해당 없음.** flood_events의 20개 레코드(13개 지점)는 전부 floodWarn에 발령 이력이 있는 기간과 겹친다.

단, 수위 레벨이 불일치하는 경우가 6건 존재한다.

### 2-1. 수위 레벨 불일치 (공식특보 > 수위기반 레벨)

flood_events는 ADVISORY로 기록됐지만 공식 특보는 경보(ALERT)로 발령된 경우.
원인: 공식 특보는 예측 수위 기반이므로, 일별 최대 관측 수위가 경보 기준에 미달해도 경보 발령이 가능하다.

| 날짜 | 지점 | 일별최대(m) | 경보기준(m) | 수위기반 | 공식특보 |
|------|------|-----------|-----------|---------|---------|
| 2024-07-17 | 동두천시(송천교) | 4.06 | 5.0 | ADVISORY | **경보** |
| 2024-07-18 | 가평군(대보교) | 5.26 | 5.6 | ADVISORY | **경보** |
| 2024-07-18 | 동두천시(송천교) | 4.54 | 5.0 | ADVISORY | **경보** |
| 2024-07-18 | 오산시(탑동대교) | 4.82 | 5.2 | ADVISORY | **경보** |
| 2024-07-18 | 평택시(진위1교) | 5.73 | 5.8 | ADVISORY | **경보** |
| 2025-07-20 | 고양시(원당교) | 2.99 | 3.0 | ADVISORY | **경보** |

> 이 6건 모두 경보 기준에 0.1~1.0m 미달한 상태에서 공식 경보가 발령됐다. **예보 수위**가 경보 기준을 초과했기 때문에 발령된 것으로 추정된다.

## 3. floodWarn에만 있고 flood_events에 없는 홍수특보

총 **15개 지점**의 공식 특보가 flood_events에 누락되어 있다.

### 3-1. designFlood 지정 지점 (13개) — 수위 임계값 미초과 추정

스크립트가 해당 지점의 수위 데이터를 처리했으나 일별 최대 수위가 주의보 기준에 미달했거나, 관측 수위 데이터를 아직 fetch하지 않은 지점들이다. **공식 특보는 발령됐으므로 예보 기반 판단이 선행**됐을 가능성이 높다.

**가능한 근거**:
- flood_events 생성 스크립트(`build_flood_events_from_waterlevel_1h.ps1`)가 모든 64개 designFlood 지점을 처리하지 않았을 가능성 (실행 당시 13개 지점만 결과)
- 또는 처리했으나 해당 날짜의 일별 최대 수위가 주의보 기준에 미달 → 예보 선행 발령 케이스

### 3-2. designFlood 미지정 지점 (2개) — 스크립트 수집 대상 외

| 지점 | wlobscd | 발령 이력 | 비고 |
|------|---------|---------|------|
| 인제군(현리교) | 1012640 | 2025-09-13 주의보, 2025-09-17 주의보, 2025-09-20 주의보 | obsFinal designFlood 미지정 → 스크립트 수집 제외 |
| 횡성군(오산교) | 1006630 | 2024-07-18·23·24, 2025-08-14 주의보 (총 4회) | obsFinal designFlood 미지정 → 스크립트 수집 제외 |

> 이 두 지점은 공식 특보가 각각 3회, 4회로 비교적 빈번하게 발령됐음에도 flood_events에 전혀 없다. DTW 분석 대상으로 포함할지 여부를 별도로 검토해야 한다.

## 4. 요약

| 구분 | 내용 |
|------|------|
| flood_events 총 레코드 | 20건 (13개 지점) |
| floodWarn 발령 사이클 | 48건 (26개 지점, designFlood 기준) |
| flood_events ∩ floodWarn (지점 기준) | 13개 지점 전부 floodWarn에도 존재 |

| 수위 레벨 불일치 (공식 > 수위기반) | 6건 — 예보 기반 경보 선행 발령 추정 |
